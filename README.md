## Features

- **12 Different Games**: Snake, Pong, Breakout, Flappy Bird, Space Invaders, Asteroids, Tetris, Memory Match, 2048, Endless Runner, Target Shooter, and Platformer
- **Ultra Performance**: Built with vanilla JavaScript and HTML5 Canvas for maximum performance
- **Responsive Design**: Works on desktop and mobile devices
- **Modern UI**: Cyberpunk-inspired design with animated particles and gradients
- **No Dependencies**: Pure HTML, CSS, and JavaScript - no frameworks required

## How to Play

### Online (GitHub Pages)
1. Visit [https://EpicNoob22.github.io/Game-website/](https://EpicNoob22.github.io/Game-website/)
2. Click on any game card to start playing
3. Use keyboard controls as shown in each game
4. Press ESC to close the game modal

### Local
1. Open `index.html` in your browser
2. Click on any game card to start playing
3. Use keyboard controls as shown in each game
4. Press ESC to close the game modal

## Controls

- **Arrow Keys / WASD** - Movement in most games
- **Space** - Jump / Shoot / Action
- **Click** - Interact in some games
- **ESC** - Close game modal

## Performance Optimizations

- Uses `requestAnimationFrame` for smooth 60fps gameplay
- Efficient canvas rendering
- Lazy loading for game previews
- CSS transforms for hardware acceleration
- Reduced motion support for accessibility
